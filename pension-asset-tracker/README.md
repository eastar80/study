# 연금 자산 리밸런싱 관리 템플릿

IRP·연금저축 등 4개 계좌에서 각각 여러 ETF를 보유하며 **분기별로 리밸런싱**하는 것을 전제로 만든 엑셀 템플릿입니다.

## 파일

- `연금자산관리_템플릿.xlsx` — 실제로 열어서 쓰는 엑셀 파일. 다운로드해서 엑셀/구글시트에서 사용하세요.
- `generate_template.py` — 위 xlsx를 생성하는 스크립트. (엑셀 파일은 바이너리라 git diff로 변경 이력을 보기 어려우므로, 시트 구조·수식을 코드로도 버전 관리하기 위해 둡니다. 구조를 바꾸고 싶으면 이 스크립트를 수정한 뒤 `python3 generate_template.py`로 다시 생성하세요.)
- `scripts/` — 로컬 PC에서 실행하는 자동화 스크립트 (아래 참고).

## 시트 구성

| 시트 | 역할 |
|---|---|
| 사용법 | 전체 사용법과 분기별 루틴 안내 |
| 대시보드 | 총자산, 계좌별 요약, 목표비중 대비 괴리 TOP5 한눈에 보기 |
| 계좌설정 | 4개 계좌 × ETF × 목표비중(%) 등록 (예시 데이터 → 실제 종목으로 교체) |
| ETF전체목록 | 상장된 모든 ETF의 티커·이름 참고용 목록. 종목 추가할 때 이름으로 찾아 티커를 복사 |
| 현황_리밸런싱 | 보유수량·현재가만 입력하면 현재비중/목표비중 괴리·매수매도 수량 자동 계산 |
| 리밸런싱_히스토리 | 실제 체결한 매수/매도 내역 로그 |
| 시계열_스냅샷 | 분기별 계좌별 총자산 스냅샷 (시계열 추이 데이터 원본) |
| 차트 | 총자산 추이, 계좌별 자산 추이, 현재비중 vs 목표비중, 계좌별 자산배분 파이차트 |

## 자동화 스크립트 (scripts/)

한국거래소(KRX) 공개 데이터만 사용합니다 — 증권사 계정 로그인/연동이 전혀 필요 없습니다.

```bash
cd pension-asset-tracker
pip install -r scripts/requirements.txt
python3 scripts/fetch_prices.py       # 계좌설정에 등록된 ETF들의 최근 종가를 조회해 현황_리밸런싱의 '현재가'를 자동 입력
python3 scripts/log_rebalance.py      # 현황_리밸런싱에서 매수/매도가 필요한 종목을 오늘 날짜로 리밸런싱_히스토리에 초안 기록
python3 scripts/refresh_etf_list.py   # ETF전체목록 시트를 최신 상장 ETF 전체 목록으로 갱신
```

- `fetch_prices.py`: 최근 **영업일 종가** 기준입니다(무료 공개 데이터라 실시간 장중가는 제공되지 않습니다). 분기 리밸런싱 판단에는 충분한 정확도입니다.
- `log_rebalance.py`: 네트워크가 필요 없습니다. 이미 시트에 입력된 보유수량·현재가만으로 계산하며, 매수/매도가 필요한 종목만 오늘 날짜로 `리밸런싱_히스토리`에 추가합니다. 체결단가는 조회 시점 가격으로 "추정" 기록되므로, 실제 주문 체결 후 체결단가(및 수량이 다르면 수량도) 확인/수정만 하면 됩니다 — 직접 7개 필드를 입력하던 것을 값 확인 수준으로 줄여줍니다.
- 세 스크립트 모두 기본적으로 같은 폴더의 `연금자산관리_템플릿.xlsx`를 대상으로 하며, `python3 scripts/fetch_prices.py 경로.xlsx` 처럼 파일 경로를 인자로 넘기면 다른 파일에도 쓸 수 있습니다.
- 내부적으로 [`pykrx`](https://github.com/sharebook-kr/pykrx) 라이브러리를 사용합니다. 기본 종목 조회 기능은 로그인 없이 동작하며, `KRX_ID`/`KRX_PW` 환경변수는 필요하지 않습니다(설정하지 마세요).

## 분기 루틴 (약 10분)

1. `python3 scripts/fetch_prices.py` 실행 → `현황_리밸런싱`의 현재가 자동 갱신
2. 증권사 앱에서 4계좌 각각의 실제 보유수량을 확인해 `현황_리밸런싱`에 입력 → 매수/매도 수량 자동 산출 확인
3. 산출된 대로 각 계좌에서 실제 주문 실행
4. `python3 scripts/log_rebalance.py` 실행 → `리밸런싱_히스토리`에 오늘 날짜로 매수/매도 초안 기록, 체결가만 확인/수정
5. `시계열_스냅샷`에 이번 분기 계좌별 합계금액 한 줄 추가

## 참고

- `계좌설정`과 `현황_리밸런싱`은 행 순서가 1:1로 대응하도록 설계되어 있습니다. 계좌설정에 종목을 추가/삭제하면 현황_리밸런싱에도 같은 위치에 행을 추가/삭제해야 합니다. 새 종목의 티커는 `ETF전체목록` 시트(또는 `refresh_etf_list.py` 실행 후)에서 이름으로 찾아 복사하세요.
- 이 저장소 개발 환경은 아웃바운드 네트워크가 방화벽으로 제한되어 있어(KRX/증권사 도메인 접근 불가), `fetch_prices.py`/`refresh_etf_list.py`의 실제 KRX 조회는 이 환경에서 직접 실행 검증하지 못했습니다. `pykrx` API 시그니처를 문서로 확인하고 openpyxl 기록 로직은 모의 데이터로 단위 검증했습니다 — 실제 실행 결과가 예상과 다르면 알려주세요. `log_rebalance.py`는 네트워크가 필요 없어 실제 데이터로 전체 동작을 검증했습니다.
- 이 환경에서는 LibreOffice headless 변환도 동작하지 않아 실제 엑셀에서의 수식 재계산 검증은 못했습니다.
