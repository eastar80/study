# 한국 주식 대시보드

기업명이나 종목코드를 입력하면 **주가 · 최근 뉴스 · 최근 공시 바로가기**를 한 화면에서 보여주는 정적 대시보드입니다. 빌드 도구나 API 키 없이 브라우저만으로 동작합니다.

**배포 주소:** https://eastar80.github.io/study/stock-dashboard/

## 기능

- **주가**: 현재가, 전일 대비 등락(한국 관습에 따라 상승은 빨강·하락은 파랑), 최근 3개월 추이 라인 차트
- **최근 뉴스**: 해당 기업 관련 Google News 기사 목록
- **최근 공시**: 금융감독원 전자공시시스템(DART)의 해당 기업 공시 페이지 바로가기
- 기업명 자동완성 및 6자리 종목코드 직접 입력 지원 (코스피·코스닥)

## 데이터 출처

| 항목 | 출처 | 비고 |
| --- | --- | --- |
| 주가 | Yahoo Finance | 무료·키 불필요 |
| 뉴스 | Google News RSS | 무료·키 불필요 |
| 공시 | 금융감독원 DART | 원문 API는 키가 필요해 검색 페이지 링크로 대체 |

정적 호스팅에서는 브라우저가 외부 API를 직접 호출할 때 CORS 제약을 받으므로, 무료 공개 CORS 프록시(`r.jina.ai` 등)를 여러 개 폴백 체인으로 경유합니다. 공개 프록시 특성상 응답이 지연되거나 일시적으로 실패할 수 있습니다.

## 한계

- **공시 원문 목록은 표시하지 않습니다.** 한국 공시 공식 소스인 DART는 API 키가 필수라, 정적 페이지에서는 DART 검색 페이지로 연결하는 방식이 최선입니다.
- 공개 프록시에 의존하므로 안정성이 보장되지 않습니다. 실서비스로 쓰려면 서버리스 함수(예: Vercel)를 두고 API 키를 안전하게 처리하는 구성이 필요합니다.
- 표시되는 정보는 참고용이며 투자 판단의 근거로 사용하지 마세요.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조 |
| `styles.css` | 디자인 시스템 및 스타일 |
| `tickers.js` | 종목명↔종목코드 매핑, 검색/자동완성 |
| `api.js` | 주가·뉴스 조회, CORS 프록시 폴백, DART 링크 |
| `chart.js` | 의존성 없는 인라인 SVG 라인 차트 |
| `app.js` | 검색 오케스트레이션 및 렌더링 |

## 로컬에서 열기

정적 파일이라 별도 빌드가 없습니다. 다만 `file://`로 열면 프록시 요청이 막힐 수 있으니 간단한 로컬 서버를 권장합니다.

```bash
cd stock-dashboard
python3 -m http.server 8000
# http://localhost:8000 접속
```
