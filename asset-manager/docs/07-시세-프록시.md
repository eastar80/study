# 시세·환율 프록시 배포

브라우저는 CORS 때문에 Yahoo Finance를 직접 부를 수 없다. 중계 하나를 두어야 한다.

**Google Apps Script로 만든다**(확정). 이미 쓰는 Google 계정 안에서 끝나고, 브라우저만으로 배포할 수
있어 새 업체 가입도 CLI도 필요 없다. 하루 2만 요청 한도는 개인 사용에 한참 남는다.

스크립트는 `asset-manager/proxy/quotes.gs` 다.

**이 프록시로는 보유 수량이나 금액이 가지 않는다.** 종목 심볼만 보낸다. 그래서 URL이 새더라도
알려지는 것은 관심 종목 목록뿐이고, 자산 규모는 알 수 없다.

---

## 1. 스크립트 만들기

1. https://script.google.com 에서 **새 프로젝트**
2. 프로젝트 이름을 `자산관리 시세 중계` 처럼 알아볼 수 있게 바꾼다
3. 기본으로 열려 있는 `Code.gs` 의 내용을 **모두 지우고**,
   `asset-manager/proxy/quotes.gs` 의 내용을 붙여넣는다
4. 저장 (Ctrl/⌘+S)

## 2. 웹 앱으로 배포

1. 오른쪽 위 **배포 > 새 배포**
2. 톱니바퀴 > **웹 앱**
3. 설정
   | 항목 | 값 |
   |---|---|
   | 설명 | 아무거나 (`v1`) |
   | 다음 사용자로 실행 | **나** |
   | 액세스 권한이 있는 사용자 | **모든 사용자** |
4. **배포** → 권한 승인 화면이 나오면 허용
   - "이 앱은 Google에서 확인하지 않았습니다" 가 나오면 **고급 > 안전하지 않은 페이지로 이동**.
     본인이 방금 만든 스크립트이므로 정상이다.
5. **웹 앱 URL** 을 복사한다. `https://script.google.com/macros/s/…/exec` 형태다

> **"모든 사용자"가 걸리는 이유** — 앱은 로그인 없이 이 URL을 부른다. 접근 권한을 본인으로 제한하면
> 브라우저에서 부를 때 Google 로그인 화면이 돌아와 JSON 대신 HTML을 받는다. 대신 위에 적었듯 이
> URL로는 심볼만 오가므로 노출되는 정보가 없다.

## 3. 확인

복사한 URL 뒤에 파라미터를 붙여 브라우저에서 직접 열어 본다.

```
<URL>?symbols=069500.KS,TSLA,8058.T&fx=USDKRW,JPYKRW
```

이런 JSON이 나와야 한다:

```jsonc
{
  "ok": true,
  "asOf": "2026-08-18T07:00:00.000Z",
  "quotes": {
    "069500.KS": { "price": 38500, "previousClose": 38200, "currency": "KRW", "name": "KODEX 200" },
    "TSLA":      { "price": 214.3, "previousClose": 210.1, "currency": "USD", "name": "Tesla, Inc." },
    "8058.T":    { "price": 2780,  "previousClose": 2750,  "currency": "JPY", "name": "Mitsubishi Corp" }
  },
  "fx": {
    "USDKRW": { "rate": 1385.2, "unit": "1", "note": "KRW per 1 unit of USD" },
    "JPYKRW": { "rate": 9.12,   "unit": "1", "note": "KRW per 1 unit of JPY" }
  }
}
```

**`JPYKRW` 이 9 근처인지 확인한다.** 900 근처면 `원/100엔` 표기이고, 이 프로젝트가 이미 한 번
100배로 틀린 그 차이다(`06-포트폴리오.md` §1). 프록시가 **항상 원/1단위**로 주기로 정했으니 9가
맞다.

한 심볼만 실패하면 그 심볼에만 `error` 가 담기고 나머지는 정상으로 온다. 하나 때문에 전체가 비면
원인을 좁힐 수 없기 때문이다.

## 4. 앱에 넣기

배포한 URL을 **환경 설정 > 시세·환율 프록시** 에 붙여넣는다. 저장 위치는 이 기기의
`localStorage` 이고 **저장소에는 커밋하지 않는다.** 접근 권한을 주는 종류의 비밀은 아니지만(심볼만
오간다), 남이 불러 owner의 Apps Script 할당량을 쓸 수 있는 주소가 공개 소스에 있을 이유는 없다.

그다음 **포트폴리오 > 현재 시세 > 시세 불러오기**. 환율 배지와 종목별 현재가·평가금액이 채워진다.

`/dev` 주소를 붙여넣으면 저장할 때 거부한다 — 편집자만 열 수 있어 앱에서는 JSON 대신 로그인 HTML이
온다. 그 상황이 실제로 발생하면 오류 메시지가 "액세스 권한이 있는 사용자" 를 확인하라고 알려준다.

`script.google.com` 은 이 저장소를 만든 에이전트의 환경에서 차단되어 있어, **실제 응답 확인은 사용자만
할 수 있다.** 앱은 위 스키마를 가정해 붙였고, 필드 이름이 다르면 화면이 "시세를 받지 못했습니다" 로
그 종목을 나열한다.

## 한계

**국내 공모펀드는 Yahoo에 없다.** 예: `KB스타미국나스닥100인덱스`. 원본 Asset Manager 화면에서도 이
종목만 52주 레인지가 `N/A` 였으니 같은 한계를 겪는 것으로 보인다. 기준가 수동 입력으로 두고, 금융투자
협회 공시 연동은 나중에 검토한다.

**캐시 15분.** 월말 잔액을 적는 앱이라 분 단위 시세가 필요하지 않고, 호출량도 줄어든다.

## 티커 정규화는 앱이 한다

시트의 티커 표기가 출처마다 다르다 — `8001.T`(야후) · `BATS: ECH`·`NasdaqGs:hsai`(구글) ·
`ief`(소문자) · `O` · 6자리 KRX 코드. 프록시는 **받은 심볼을 그대로 조회**하고, 변환은 앱의
`web/src/lib/quotes/symbol.ts` 가 순수 함수로 한다(테스트로 고정).

| 거래소 | 규칙 | 예 |
|---|---|---|
| KRX | `.KS` 붙임 | `069500` → `069500.KS` |
| kosdaq | `.KQ` 붙임 | `086520` → `086520.KQ` |
| JPX | `.T` 붙임 | `8058` → `8058.T` |
| USD | 그대로, 대문자 | `ief` → `IEF` |
| 접두사 | 콜론 뒤만 사용 | `NasdaqGs:hsai` → `HSAI` |

이미 접미사가 있는 티커에는 **덧붙이지 않는다** — `8001.T.T` 는 아무 종목도 아니다. 모르는 거래소에는
접미사를 **추측하지 않고** 그렇다고 보고한다. 잘못된 접미사는 다른 회사의 시세를 조용히 가져오므로
아무것도 안 가져오는 것보다 나쁘다.
