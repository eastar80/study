## 1. 서비스 개요

개인용 통합 자산관리 웹앱. 세 축으로 구성된다고 소개한다.

| 축 | 원본 문구 |
|---|---|
| 통합 자산 관리 | 분산된 자산 현황을 한곳에서 모니터링하고 시각화된 차트로 재정 상태를 확인 |
| 포트폴리오 분석 | 투자 자산의 수익률과 배당 현황을 실시간 분석 |
| 스마트 가계부 | 매달 반복되는 고정비와 지출을 기록하여 월별 흐름을 정밀 분석 |

- 인증: **Google OAuth 단독** (이메일/비밀번호 가입 없음)
- 배포: Google Cloud Run (`us-west1`)
- 라우팅: **해시 라우팅** SPA (`/#dashboard`). 미인증 시 해당 경로를 유지한 채 로그인 카드 오버레이

## 3. 모듈 1 — 대시보드

> "나의 전체 자산 현황과 흐름을 한눈에 파악하는 통합 컨트롤 타워"

### 3.1 자산 현황
KPI 카드 4개. 각 카드 하단에 `전월 대비 <증감액> (<증감률>)`.

| 카드 | 색 |
|---|---|
| 순 자산 | 검정 |
| 총 자산 | 녹색 |
| 총 부채 | 빨강 |
| 레버리지 비율 (%) | 검정 |

### 3.2 자산 및 부채 구성 현황
가로 스택바 2개 + 범례.

- 자산: 부동산 63.4% / 금융자산 35.5% / 현금성 자산 1.1%
- 부채: 담보대출 76.9% / 신용대출 16.7% / 학자금대출 6.4%

### 3.3 부채 상세 분석
- `월 예상 이자` (부가 표기 "연 ~")
- `평균 이자율 %` (부가 표기 "가중평균 금리")
- 대출별 카드: 주택담보대출 / 사내대출 / 학자금대출 — 각각 **상환율 진행바**

### 3.4 포트폴리오 현황
- `총 자산` — "총 관리 자산 규모" + **목표 대비** 진행바
- `이번달 성과` — 이번달 누적 손익 + 목표 대비 진행바
- `올해 성과` — 올해 누적 손익 + 목표 대비 진행바
- 개별 종목 카드 (로고 + 종목명 + 보유수량 + 수익률)
  관측: Tesla, Inc. / Palantir Technologies Inc. / KODEX AI반도체TOP2플러스

### 3.5 수입/지출 현황
KPI 카드 4개. 각각 `목표`, `계획 대비`, `전월 대비` 3중 비교.

| 카드 | 부가 정보 |
|---|---|
| 수입 | 목표 / 계획 대비 / 전월 대비 |
| 지출 | 동일 |
| 저축률 (%) | 동일 |
| 주요 지출 | "최다: 삼성카드", "결제 수단 N종 사용", 수단별 태그 |

### 3.6 목표 금액 달성 계산기

| 입력 | 예시값 | 비고 |
|---|---|---|
| 목표 금액 | 1,000,000,000 원 | |
| 현재 자산 | 676,866,035 원 | **[포트폴리오 연동]** 버튼 |
| 투자 원금 | 448,679,548 원 | **[포트폴리오 연동]** 버튼 |
| 월 적립금 | 1,000,000 원 | |
| 연 수익률 | 7 % | |

`[시뮬레이션 실행]` → 결과 패널

- "목표 금액 10억원 만들기" / **4년 7개월** / 배지 `도달 가능` / "연 7% 복리 가정"
- 차트 "연도별 투자 결과": 평가금액(영역) + 투자 원금(점선) + 투자수익(선)
- x축 라벨이 `2027년(5개월)`처럼 **경과 개월수를 병기**

## 4. 모듈 2 — 자산 관리

> "월별·항목별 자산 및 부채 잔액을 정밀하게 기록하고 관리하는 자산 대장"

**이 모듈이 서비스의 데이터 원본이다.** 대시보드의 자산 KPI·구성비·추이는 모두 여기서 집계된다.

### 4.1 카테고리 체계 (2단계)
- 상위구분: 예적금, 주식, 부동산, 대출 …
- 하위구분: 국민은행, 한국투자증권, 전세자금대출 …
- 하위구분은 사용자가 직접 관리
  - **이름 수정**: hover 시 나타나는 연필 아이콘 → 인라인 편집
  - **숨김/복원**: 눈 아이콘으로 숨김, "숨김 해제 모달"에서 복원
  → 카테고리는 하드코딩이 아니라 **사용자별 마스터 데이터**

### 4.2 상세 탭 = 자산 대장 그리드

**행 = 항목, 열 = 월**인 스프레드시트형 표.

```
             │ 26/03  26/04  26/05  26/06  26/07  26/08 │
[현금성 자산]│                                          │ + 추가
  주택청약저축│  ****   ****   ****   ****   ****   **** │
  현금        │  ****   ****   ****   ****   ****•  **** │  ← • = 메모 표시자
  예금/적금/CMA│ ****   ****   ****   ****   ****•  **** │
  기타(상품권)│  ****   ****   ****   ****   ****   **** │
▼ 부채 합계   │  ****   ****   ****   ****   ****   **** │  ← 합계행(하이라이트)
[담보대출]    │                                          │ + 추가
  주택담보대출│  ****   ****   ****   ****   ****   **** │
              │  **%    **%    **%    **%    **%    **% │  ← 대출은 금리 2단 표기
  주식담보대출(iM)
  펀드담보대출(한투)
```

- 그룹 헤더에 컬러 배지 + `+ 추가` 버튼
- 합계 행은 배경 하이라이트 + chevron으로 그룹 접기/펼치기
- **대출 항목만 셀이 2단**: 금액 + 금리(%). 이것이 "가중평균 금리", "월 예상 이자"의 계산 소스
- 셀 클릭 → 인라인 편집 (금액 / 메모), 메모가 있으면 셀에 작은 점 표시
- **CSV 다운로드 / 업로드**로 백업·복원

### 4.3 홈 탭
- 자산 현황 KPI 4개 — 단, 여기서는 비교 기준이 **전년 대비** (대시보드는 전월 대비)
- **월별 노트** 카드: "2026년 07월 자산 관리 노트" + 상태 배지 `작성완료` + `[메모 수정]`
  - 예시 본문: `- 부동산 시세차익 업데이트 ; +1.3억원` / `- 광주은행 금리 인상 ; +0.5%p`
  - 그 달 자산이 왜 움직였는지 남기는 용도 → 추이 차트 변곡점 설명
- 자산 및 부채 구성 현황 / 부채 상세 분석 / 상세 내역 (섹션별 ⚙ 설정)

### 4.4 자산 및 부채 추이 차트
- 기간 토글 `[12M] [전체]`
- 이중축 복합 차트: 스택 막대(순 자산 + 총부채) + 선(부채 비율)

## 5. 모듈 3 — 포트폴리오

> "국내/해외 주식, ETF, 펀드 등 투자 보유 종목과 수익률·배당금을 실시간 추적"

### 5.1 지수/지표
- 토글 `[지수] [시장 지표]`
- 지수 7종을 **MTD / YTD 두 개의 막대**로 비교
  KOSPI · KOSDAQ · S&P 500 · NASDAQ · Russell 2000 · Nikkei 225 · EURO STOXX

### 5.2 보유 현황 — 3가지 뷰

뷰 토글 `[표] [차트] [계좌]` + 새로고침 + ⚙

**표 뷰** — 10개 컬럼

| 자산명 | 비중 | MTD | YTD | 52W RANGE | 수익률 | 평가손익 | 평가금액 | 보유수량 | 평균단가 |
|---|---|---|---|---|---|---|---|---|---|

- 행 좌측에 **핀(고정)** 아이콘 + 종목 로고 + 종목명
- `52W RANGE`는 저가—현재가(볼드)—고가 슬라이더 위젯, 통화기호 자동 전환($ / ₩)
- 데이터 없는 항목(공모펀드 등)은 `N/A`
- 관측 종목 구성: 해외 개별주(TSLA, PLTR) + 국내 ETF(TIGER·KODEX) + 국내 공모펀드(KB스타…)

**차트 뷰 = 섹터별 트리맵**
- 기간 드롭다운 (YTD 등)
- 그룹: `CONSUMER CYCLICAL` / `FUND·ETF` / `TECHNOLOGY`
- 블록 크기 = 비중, 색 = 수익률 (녹색 +, 빨강 −, 명도로 강도)
- → 종목별 **섹터 분류 데이터**가 필요

**계좌 뷰** — 증권사 계좌별 그룹핑 (미확인)

### 5.3 배당
- 헤더 우측 토글 `[실수령액]` — **세전 / 세후 전환**
- "2026년 예상 배당금" + 배지 `배당률 0.05%`
- 주석: *"하단 그래프의 배당월은 **배당기준일(Ex-Date)** 기준으로 표기됩니다."*
- 월별 막대 차트(1~12월), 현재 월 강조 = 배당 달력
- 우측 "N월 배당 리스트"
  - 종목 카드: 로고 + 종목명 + **종목코드 배지** + `689주 · 주당 65원` + 금액
    + `배당월: 1, 4, 7, 10` + 펼치기
  - 펼치면 "배당 내역 (전년도 1월 ~ 현재)": `2026-07-30 65원` / `2026-04-29 57원` …

### 5.4 거래 기록
FAB(+) → 모달. **매수 / 매도 / 배당금 입금** 3종.
배당 등록 시 종목 드롭다운에서 고르면 적요란에 종목명이 자동 입력된다.

## 6. 모듈 4 — 가계부

> "수입·지출을 기록하고 월별 예산을 관리하는 현금흐름 수첩"

### 6.1 거래 유형
**수입 / 지출 / 이체** 3종. 이체는 "자산 계좌 간 자금 이동"으로 명시 → 자산 대장과 연결된다.

### 6.2 지출 분석
- 토글 `[카테고리] [캘린더]`, 우측 `[⚙ 예산 설정]`
- 좌측: 대분류 카드 리스트 — 분류명 + `예산 대비 NNN%` + 금액 + 진행바
  - 예산 초과 시 바가 **빨강**으로 전환 (Tax/Interest 104.9%, Health/Culture 731.4% → 빨강 /
    Eating in 99.9%, Eating out 91.4% → 보라)
- 우측: "대분류를 선택하시면 중분류 상세 내역이 표시됩니다."
  → 가계부 카테고리도 **대분류 > 중분류 2단계**, 좌우 마스터-디테일 구조
- 카테고리명이 영문(사용자 자유 입력)

### 6.3 상세 내역 표

| 날짜(요일) | 유형 | 카테고리 경로 | 적요 | 결제수단 | 금액 |
|---|---|---|---|---|---|
| 2026-07-23(목) | 지출 | Health/Culture > 주택화재보험 | 삼성화재 | 현금 | **** |
| 2026-07-23(목) | 지출 | Eating out > 외식 | 카츠야미, 고구마돈카츠 | 기타 | **** |
| 2026-07-23(목) | 지출 | Health/Culture > 병원비 | 허리 주사 | 신한카드 | **** |
| 2026-07-22(수) | 지출 | Eating out > 편의점 | 샌드위치 | 신한카드 | **** |

- 페이지네이션 10건/페이지 (`11-20 / 총 82개 내역`)
- **결제수단**이 별도 차원 (현금 / 삼성카드 / 신한카드 / 기타) → 대시보드 "주요 지출" 카드의 소스

### 6.4 수입 및 지출 추이
복합 차트: 막대(저축률) + 선 2개(수입, 지출), 12개월

## 8. 역설계한 데이터 모델 (초안)

원본 화면에서 필요한 최소 엔티티. 필드는 화면에 드러난 것만 적었다.

```
User                      id, google_sub, email, nickname, tier(등급), role, 기준통화
Setting                   user_id, 금액마스킹, 표시섹션, 컬럼설정 …

── 자산 대장 ──────────────────────────────────────────────
AssetCategory             user_id, kind(ASSET|DEBT), name, color, sort_order
AssetItem                 category_id, name, hidden(bool), sort_order
                          ※ 대출이면 금리 관리 대상
AssetSnapshot             item_id, year_month, amount, memo
                          ※ 대장 셀 하나 = 이 레코드 하나
DebtRate                  item_id, year_month, annual_rate    ← 대출 셀의 2단째
MonthlyNote               user_id, module(ASSET|LEDGER|PORTFOLIO), year_month,
                          body, status(작성중|작성완료)

── 포트폴리오 ─────────────────────────────────────────────
Account                   user_id, 증권사명, 계좌별칭        ← "계좌 뷰"용
Security                  ticker, name, market, currency, sector, logo_url
Holding                   (Trade 집계 뷰) 수량, 평균단가
Trade                     account_id, security_id, type(BUY|SELL|DIVIDEND),
                          date, quantity, price, amount, fee, tax, memo
Quote                     security_id, date, close, w52_low, w52_high   ← 시세 캐시
DividendHistory           security_id, ex_date, pay_date, dps
IndexQuote                index_code, date, close                        ← 지수 7종

── 가계부 ─────────────────────────────────────────────────
LedgerCategory            user_id, parent_id(대분류/중분류), name, sort_order
PaymentMethod             user_id, name(현금/삼성카드/신한카드/기타)
LedgerEntry               user_id, date, type(INCOME|EXPENSE|TRANSFER),
                          category_id, payee(적요), method_id, amount,
                          from_item_id, to_item_id   ← 이체일 때 자산 항목 연결
Budget                    user_id, year_month, category_id, amount

── 타임라인 ───────────────────────────────────────────────
TimelineEntry             user_id, date, title, body, tags[], pinned(bool)

── 목표 ───────────────────────────────────────────────────
Goal                      user_id, scope(총자산|월성과|연성과|수입|지출|저축률),
                          period, target_amount
```

핵심 관계 하나: **가계부의 이체(TRANSFER)와 포트폴리오의 매수/매도는 결국 자산 대장의 잔액을
바꾼다.** 원본이 이 정합성을 자동으로 맞추는지, 아니면 대장을 사용자가 손으로 갱신하는지는
화면만으로 확정할 수 없다. 자산 대장이 "월별 스냅샷"이고 셀을 직접 편집하는 구조인 것으로 보아
**수동 갱신(또는 반자동)** 쪽에 가깝다.
